## 🚀 Featured Project — SSH Transfer Pro

A desktop **DevOps workstation** for high-speed remote file transfers over SSH/SFTP.

- 📁 Remote file browser with folder drill-down + exclude checkboxes
- ⚡ Tar stream / SFTP / SCP transfer engines
- 🖥️ One-click native terminal launcher (Windows Terminal, PowerShell, cmd)
- 📟 SSH diagnostic console with remote command input
- 🪟🐧🍎 Windows, Linux & macOS installers via Electron
